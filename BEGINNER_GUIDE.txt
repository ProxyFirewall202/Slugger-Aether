SLUGGER NEO v0.5.3.1 — BEGINNER GUIDE

WHAT CHANGED
- Fixed touch-device detection so large Windows/macOS desktop browsers don't show mobile controls just because touch points or coarse-pointer capabilities are reported.
- Touch controls are hidden while the hub, authentication, pause, run summary, wave selection, upgrade screens, or non-playing PvP phases are displayed.
- Hold-to-shoot now uses a dedicated mobile-held latch so compatibility mouseup events can't stop firing while a finger is still down.
- Projectile origin is aligned with the visible weapon muzzle.
- Mobile control sizes are slightly reduced.

HOW TO PUBLISH THIS UPDATE
1. Download and extract the full release ZIP.
2. Open the extracted docs folder.
3. Open your existing GitHub repository and navigate to its top-level docs folder on the main branch.
4. Upload the contents of this release's docs folder into that existing docs folder, replacing files when prompted. Keep index.html, manifest.webmanifest, css/, icons/ and js/ together. Do not create docs/docs.
5. Commit the changed files to main. GitHub Pages should continue to use main /docs.
6. Wait for the Pages build to finish, then reload the site on PC and iPhone. If installed as a Home Screen app, fully close and reopen it if it continues showing cached files. The index now adds ?v=0.5.3.1 to CSS/JS URLs to help force the new assets to load.

DO NOT UPLOAD TO GITHUB PAGES
The cloudflare-worker folder is not part of the public site. Keep it separate from docs/.

MOBILE CONTROLS
- MOVE: press and drag the left virtual joystick. Direction and drag distance set movement.
- SHOOT: hold the large green button to fire. It automatically targets the nearest live enemy and switches targets as enemies are defeated.
- SPECIAL: tap once to use the equipped special.
- ELEMENT: tap ‹ or › to cycle backwards/forwards through elements you've unlocked.
- HIDE/SHOW CONTROLS: the small button near the upper-left hides/restores the touch overlay. Your preference is stored in that browser.

PC CONTROLS
Keyboard and mouse behaviour is retained: WASD/arrow keys to move, mouse to aim, hold left mouse button to shoot, right mouse button or Space for special, number keys 1–6 to choose elements, and Q/E to cycle elements. Mobile controls should remain hidden while using a full-size desktop.

TURN AND NETWORKING
The Worker endpoint is already set in docs/js/06-turn-peer-lifecycle.js. Do not paste Metered credentials into the public game or change the endpoint for a normal game update. The Metered API key remains a Cloudflare Worker Secret.

SCRIPT ORDER
All 12 JS files in docs/js are loaded as synchronous classic scripts in the exact order listed in docs/index.html. Do not add async/defer and do not reorder the scripts. Publish all updated docs contents, not only index.html, because this hotfix changes CSS/JavaScript.

TEST CHECKLIST
1. On PC, open every hub tab and a live run; confirm mobile controls never show and mouse/keyboard still work.
2. On a phone, open the hub; confirm controls are hidden. Start a run; controls should appear.
3. Hold SHOOT while moving the joystick. Shooting should continue until you lift your finger.
4. Check that shots visibly originate from the gun muzzle.
5. Tap SPECIAL and cycle elements.
6. Hide controls, then show them again.
7. Test portrait and landscape, then do a real two-client PvP test. Static validation cannot replace real device/network testing.

TROUBLESHOOTING
- Controls missing on mobile: ensure you're on a supported mobile/tablet user agent and in a live active run.
- Controls show on PC: check that the published index.html is the v0.5.3.1 version and hard-reload. The CSS/JS query parameter should also avoid stale module caching.
- Shoot stops while holding: fully upload the new docs contents, especially js/03-world-combat-simulation.js, js/11-mobile-touch-controls.js and js/12-input-and-startup.js.
- CSS/JS appears partly updated: upload every file in docs/ and preserve the script filenames and order.
