SLUGGER NEO v0.5.2 — START HERE

1. Upload the whole docs/ folder to the top level of your GitHub repository (or replace the files inside your existing docs/ folder).
2. In Settings > Pages, select branch main and folder /docs.
3. Keep cloudflare-worker/ outside docs/; it must not be served as public game content.
4. Wait for GitHub Pages deployment, then hard-reload the game.

NO REDESIGN
The original CSS rules and existing game logic are split into manageable files. No intentional gameplay, balance, layout, or styling changes are part of v0.5.2; the version label is updated.

MODULE STRUCTURE
- docs/index.html: markup, PWA metadata and ordered script references
- docs/css/styles.css: CSS
- docs/js/01-...-11-...js: game systems by feature
- docs/manifest.webmanifest and docs/icons/: PWA assets

When publishing a modular release, publish the updated docs/ contents—not just index.html when JS or CSS files also changed. Preserve TURN_CREDENTIALS_ENDPOINT in docs/js/06-turn-peer-lifecycle.js.

SCRIPT ORDER
The 11 JavaScript files are synchronous classic scripts; do not add async/defer or reorder them.
