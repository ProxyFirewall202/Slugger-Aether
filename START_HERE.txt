SLUGGER NEO v0.5.3.1 — START HERE

WHAT'S FIXED
- Mobile touch controls are hidden on desktop-primary environments and on all menus/overlays.
- Mobile hold-to-shoot remains active across compatibility mouse events and releases when the touch ends.
- Projectile origin now matches the visible weapon muzzle to remove the gun/shot offset.
- Mobile touch targets are slightly smaller.

PUBLISH
1. Extract this release package.
2. Upload the whole contents of docs/ into your repository's existing top-level docs/ folder, replacing files where prompted. Keep css/, icons/, js/, manifest.webmanifest, and index.html together.
3. Leave cloudflare-worker/ outside docs/; it must not be served as public game content.
4. In Settings > Pages, choose branch main and folder /docs.
5. Wait for deployment, then hard-reload the game. The CSS/JS paths include a v0.5.3.1 query parameter to reduce stale-cache issues.

IMPORTANT
- Keep all 12 script files in docs/js/ and preserve their filenames.
- Do not add async/defer or reorder script tags in index.html.
- Preserve TURN_CREDENTIALS_ENDPOINT in js/06-turn-peer-lifecycle.js. Your Cloudflare Worker and Metered setup do not need changes for this game update.
- For routine game updates, publish the full updated docs/ contents, not just index.html when JS/CSS changed.
