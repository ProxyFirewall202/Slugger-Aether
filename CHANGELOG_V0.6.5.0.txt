Slugger (NEO) v0.6.5.0

- Tier labels use Roman numerals I–X across loot boxes, equipment, set cards, and stats filters.
- Added an animated full-screen run-end sequence: death effect, run statistics, sequential loot-box openings, and a combined reward summary.
- Loot boxes earned during a solo run are opened automatically one at a time; each result identifies Lucky, Standard, or Unlucky.
- Warp payouts now scale upward by loot-box tier before the existing collection-based diminishing-return multiplier.
- Loot Boxes tab lists only loot boxes currently owned; the market remains available for previously discovered boxes.
- Added a multiplayer round-summary loot opening step before the existing Continue/ready handshake.

Cloudflare Worker, Firebase configuration, Metered TURN credentials, and PeerJS signalling endpoints are unchanged.
