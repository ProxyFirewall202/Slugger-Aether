SLUGGER NEO v0.6.3.0 — QUICK START

WHAT TO UPLOAD
Use the docs/ folder inside this archive.

STEPS
1. Extract the ZIP.
2. Open your GitHub repository.
3. Open the existing top-level docs/ folder on the main branch.
4. Upload the CONTENTS of the package's docs/ folder, replacing the previous game files.
5. Ensure there is exactly one docs/index.html path in the repository (not docs/docs/index.html).
6. Commit the changes and wait for GitHub Pages to finish deploying.
7. Reload the game; close and reopen the iOS Home Screen app if it shows cached content.

DO NOT
- Upload cloudflare-worker/ into docs/.
- Change the Metered TURN credentials or Cloudflare Worker for this update.
- Expect full unique item animations or the new outcome tiers yet; these are later sub-phases.

TEST THESE FIRST
- Sign in and load the hub.
- Check the 30 set names and their five item definitions are present.
- Open the Loot Box market and verify Scrap / Ironclad naming.
- Equip one of the new set pieces; make sure stats and tracker render.
- Start a run and check wave loot-box drops.
- Try a 1v1 session and confirm the upgrade HUD still shows Warp / Loot Boxes.

If something fails, note the screen and exact error before reloading.
