Slugger NEO v0.6 — Phase 1 Quick Start

1. Extract slugger_neo_v0.6_phase1_complete.zip.
2. Upload the CONTENTS of docs/ into your current GitHub repository's top-level docs/ folder on main.
3. Keep index.html, manifest.webmanifest, icons/, css/, and js/ together. Commit the changes.
4. Leave GitHub Pages set to main /docs.
5. No Cloudflare Worker update is required for Phase 1. Preserve the existing Worker and secrets.
6. Test crate subtabs (owned crates only), item category grid, Weapon Stats & DPS, Sets & Progress, and the 1v1 60-second upgrade screen.

See README.txt and CHANGELOG_V0.6_PHASE1.txt for details. Phase 2 and Phase 3 are deferred until Phase 1 has been tested and any bugs fixed.
