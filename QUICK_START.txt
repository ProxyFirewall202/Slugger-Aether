3. Commit changes and wait for GitHub Pages to publish.
4. Fully reload the game. Close/reopen installed iOS PWA if necessary.
5. Test a run with an awakened Spirit Slug equipped.

No Cloudflare Worker or Firebase configuration changes are needed.
