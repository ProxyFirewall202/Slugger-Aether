Slugger v0.6.0.1 — Quick Start

1. Extract the Docs ZIP.
2. Upload the CONTENTS of docs/ into your repo's top-level docs/ folder on main.
3. Commit the changes; keep GitHub Pages on main /docs.
4. Reload the game (fully close and reopen the installed iOS PWA).
5. Try username sign-in again.

No Cloudflare Worker update is needed for this client-side hotfix.
