3. Commit to main; keep GitHub Pages on main -> /docs.
4. Reload the website. Fully close/reopen the installed iOS PWA if it serves cached files.

TEST THESE FIRST
- Check tier labels for the loot boxes, set cards and each item in Equip Slot Grid/Equipment Stats.
- Open boxes and verify the explicit Lucky/Standard/Unlucky result.
- Verify the 10 tier filter includes Tier 1–Tier 10.
- Try several opens of the same box and confirm Warp/item rewards taper as more pieces from its set are collected.
- Smoke-test a normal run and a real two-device 1v1 session if available.

Local simulated tests passed, but live cloud and two-peer network tests were not performed.

ANTI-GRIND RULE
Random enemy loot-box drop chance scales down per box family as you collect its five set pieces (7% base down to 1.4% at full set). Guaranteed wave/boss milestone boxes are unaffected. Warp from a box also scales down to 20% at full set collection.
