SLUGGER NEO v0.6.6.2 — QUICK START

1. Extract the release archive.
2. Open the docs/ folder.
3. Upload every item INSIDE docs/ into the existing top-level docs/ directory in your GitHub repository's main branch.
4. Do not make a docs/docs/ folder.
5. Commit changes; keep Pages configured for main -> /docs.
6. Let Pages deploy, then reload the site. For the iPhone Home Screen app, fully close it and open again to refresh cached scripts.

WHAT TO TEST
- Loadout: Weapons, Shields, Armor, Boosts & Charms, and Spirit Slugs should have clearly varied silhouettes, not just recoloured copies.
- Open the set tracker and Equipment Stats: the same item art should appear there.
- Earn and open a loot box: its equipment SVGs should match the Loadout artwork.
- Start a run with armor equipped and verify the animated shell remains visible with eyes exposed.
- Run a quick PC round, an iPhone round, and a live 1v1 if possible.

BACKEND
No Cloudflare Worker, Firebase, Metered credentials or TURN endpoint changes are required.
