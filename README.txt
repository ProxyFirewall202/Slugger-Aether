Slugger (NEO) v0.5.1 Hotfix — GitHub Pages PWA bundle

Deploy all files/folders in this bundle to the same directory in your GitHub Pages site. Keep index.html, manifest.webmanifest, and the icons/ folder together.

On iOS 16: open the HTTPS GitHub Pages URL in Safari, tap Share, choose Add to Home Screen, and confirm Add. Launch the game from the new Home Screen icon to open it in standalone app mode. iOS does not turn an ordinary Safari tab into an app automatically; the Home Screen installation step is required.

This bundle adds a web app manifest and Apple home-screen metadata/icons. It does not add offline gameplay caching; the game loads external font, PeerJS, and Firebase resources and requires network connectivity for those services.
